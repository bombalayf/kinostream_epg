# 📺 KINO STREAM EPG

**Бесплатное EPG из телеграм каналов**

Данный проект собирает и предоставляет актуальные электронные программы передач (EPG) из открытых Telegram-каналов. Это позволяет использовать единый источник данных для вашего IPTV-плеера или медиацентра.

## 🚀 Как использовать

1.  Скопируйте ссылку на EPG из таблицы выше.
2.  Вставьте её в настройках вашего IPTV-плеера (например, TiviMate, OTT Navigator, IPTV Extreme и др.) в разделе настроек электронного телегида (EPG).
3.  Обновляйте список каналов и программу передач для просмотра актуального расписания.

## 📜 Лицензия

Данный проект является некоммерческим и создан для удобного доступа к бесплатным источникам EPG.
